# 灵感增强 0.1.2

本次为小幅修复更新，统一运行报告与实际安装版本的显示。

- 修复运行报告中的版本名仍显示为 0.1.0 的问题；报告现在使用当前安装包的实际版本名和构建号。
- 安装版本号递增至 280，已有 0.1.0 / 0.1.1 用户可通过应用内更新检查并覆盖安装。

## 更新与使用

适用于 ColorOS 15 / 16，以及已适配的一加 15 国行 ColorOS 17.0.0.102 / 17.0.0.105，需要 Root 与 LSPosed。功能可用性因机型、系统和应用版本而异；部分旧版系统继续使用原生识屏。ColorOS 17 已完成系统原包与自动化检查，仍需真机反馈。

可以直接覆盖安装，原有设置会保留。也可在「关于灵感增强 → 应用更新」检查和下载安装。更新后请重启手机，让 LSPosed 加载新版。
