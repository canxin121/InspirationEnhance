# 灵感增强 0.1.4

本次为修复更新，集中处理用户反馈的最近任务菜单、小窗长按与模块自绘界面触感问题，并补齐 ColorOS 17 的宿主适配与日志可观测性。

- 修复小窗长按没有效果、唤不出静音/全屏按钮：ColorOS 17 把 `isToBack` 从小窗信息管理器移到了任务扩展（`ITaskExt` / `TaskExtImpl`），模块仍按旧位置取值会抛 `NoSuchMethodError`，被等待回调当成“不可用”而放弃长按；现已按原包实测在两个位置间回退，并在安装期预校验依赖成员。同一根因还影响浮窗后台刷新（`FLEXIBLE_BACKEND_REFRESH`）。
- 最近任务菜单：面板样式（纯白/深色 22dp 圆角）改为在 `setItems` / `popupShow` / 首次行绑定三处幂等重放，不再依赖单一展示回调；新增菜单链路埋点（面板是否生效、菜单项数量、动作、强行停止的原因码），下一次日志可直接判定视觉与缺项问题。
- 触感统一：新增统一触感入口，优先标准 effect，视图未就绪或未真正生效时回退系统振动，并接入边角轮盘、MINI 菜单按钮（静音/全屏）、桌面字母索引、应用音量窗、窗口手势预览与识屏菜单。
- ColorOS 17 适配：仅在 SystemUI 存在的 Flexible 菜单与 Shell 动效类不再在桌面误报失败；应用内状态栏回顶改读系统镜像设置；桌面索引设置读取失败改为限频并保留上次已确认值。
- 日志可观测性：链接错误会带出缺失的类或方法签名；成功路径不再写 ERROR；Provider 未就绪的 IPC 降为 WARN；高频事件仅在状态变化时记录（上一份日志中约 45% 的记录来自这类重复事件）。

## 更新与使用

适用于 ColorOS 15 / 16，以及已适配的一加 15 国行 ColorOS 17.0.0.102 / 17.0.0.105，需要 Root 与 LSPosed。功能可用性因机型、系统和应用版本而异；部分旧版系统继续使用原生识屏。

可以直接覆盖安装，原有设置会保留。也可在「关于灵感增强 → 应用更新」检查和下载安装。更新后请重启手机，让 LSPosed 加载新版。安装构建号递增至 283。

本轮依据 2026-10-12 用户日志与一加 15 ColorOS 17.0.0.102 原包（OplusLauncher / SystemUI / framework.jar / oplus-services.jar）逐项核对；小窗长按、菜单样式与触感仍需对应设备的真机反馈确认。
