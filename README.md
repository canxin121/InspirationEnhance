## 功能一览

| 功能 | 你可以做什么 |
| --- | --- |
| **窗口与多窗** | 使用 Flyme 风格小窗、迷你窗快捷菜单和联系人头像，自定义小窗数量。 |
| **边角轮盘** | 从屏幕底角滑动呼出，快速打开应用；自由编辑左右布局、层数和快捷入口。 |
| **桌面索引** | 从桌面边缘侧滑呼出应用索引，快速查找和打开应用。 |
| **最近任务** | 使用 Flyme 风格任务卡片与清理动效，查看内存占用，强行停止应用。 |
| **灵感识屏** | 提取文字、图片和视频；长按内容，快捷复制、保存或分享。 |
| **其他功能** | 轻点状态栏，让当前页面回到顶部。 |

## 安装与启用

1. **安装 APK。** 安装「灵感增强」，更新时可直接覆盖安装。
2. **启用模块。** 在 LSPosed 中启用「灵感增强」，勾选系统框架、系统界面、正在使用的系统桌面及原生识屏应用。需要长按提取的应用也要勾选。
3. **完成授权。** 打开「灵感增强」，在「运行状态」中授权 Root，再按自己的习惯调整功能。
4. **让设置生效。** 首次启用或更新后重启手机；之后调整设置，按页面提示使用「应用更改」。

安装包与更新说明见 [版本发布](https://github.com/canxin121/InspirationEnhance/releases)。应用默认自动检查新版本，也可在「关于灵感增强 → 应用更新」手动检查和下载安装。

## 常见问题

<details>
<summary><strong>安装后，功能没有生效？</strong></summary>

先查看「运行状态」，确认 Root 已授权、LSPosed 中模块已启用，并勾选了相应作用域。使用页面上的「应用更改」，或重启手机后再试。

</details>

<details>
<summary><strong>长按内容提取怎么用？</strong></summary>

在「灵感识屏」中开启「长按内容提取」，然后在已勾选的应用中长按内容。菜单出现后可以直接点按按钮，也可以保持按住，滑到按钮上选中，**松手后执行**；滑出按钮后松手则取消。

底部短横条可以拖动菜单，方便移开遮挡。没有滑入提取按钮时，仍保留应用自己的长按操作。

</details>

<details>
<summary><strong>为什么有些图片、动图或视频无法提取？</strong></summary>

不同应用版本和页面的支持情况不同，抖音、微信、QQ 等应用也可能存在尚未适配的内容。如果提示源文件不可用，或保存结果不正确，请附上应用版本和复现步骤反馈。

</details>
